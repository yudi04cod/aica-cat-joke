**"The One-Line Cat Joke That Lands"**
(`u-aldy998-the-one-line-cat-joke-that-lands-a7b18262`).

`main.ts` (Node 22, no dependencies) deterministically writes one short
original joke about cats to `/output/entry.txt`.

## The joke

> My cat learned to open doors, so now I knock before entering my own bedroom.

76 characters, one line, no network, same bytes on every run.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
